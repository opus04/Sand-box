# 시티 라운지 · CITY LOUNGE — 오윤석 개인 허브

개인용 웹 허브입니다. `index.html` 한 파일로 동작하며 GitHub Pages로 제공됩니다.

## 섹션
01 MEDIA · 02 GAMING · 03 CAMPUS & SCHEDULE(달력·시간표) · 04 D-DAY & TASKS · 05 AI & TOOLS(ChatGPT · Claude)

## 02 GAMING 전적 패널 (RECENT MATCHES)
- 닭인데요#꼬꼬댁꼬꼬(KR, League of Legends)의 최근 전적·솔로랭크 요약을 `02 GAMING` 화면 안에 표시합니다. 게임 바로가기 카드 7개는 그대로입니다.
- 데이터는 같은 폴더의 `matches.json`입니다. 화면은 5분(300,000ms)마다 `fetch('matches.json?t=' + Date.now(), {cache:'no-store'})`로 다시 불러오고, 새로고침 버튼·남은 시간 카운트다운을 함께 보여 줍니다. 갱신에 실패하면 1분 뒤 재시도하고, 이미 받아 둔 전적은 그대로 유지합니다.
- `🎮 닭인데요 게임 전적 알림` 스케줄(5분 주기)이 새 판을 감지하면 `matches.json`을 갱신해 푸시합니다. 판에 `feedback` 문자열이 있으면 AI 한줄평으로 함께 표시합니다.
- 전적 리스트 위에 최신 판(`matches[0]`)의 **AI 분석 하이라이트 카드**가 있습니다. 배지(`방금 끝난 판 AI 분석`)·승/패·챔피언·모드·포지션·KDA·시야 점수·OP 스코어와 `feedback` 전문을 보여 주고, 카드 전체가 승리(파랑)/패배(코랄) 톤으로 바뀝니다. 5분 자동 갱신([`load()` → `renderAll()` → `renderHighlight()`])마다 최신 판으로 자동 교체됩니다.
- 메인 허브 `02 GAMING` 소제목 미리보기에는 최신 판 결과와 분석 한 줄(`판테온 승 (1/2/9) · …`)이 함께 표시됩니다. 긴 문장은 말줄임 처리되고, 로드 전·실패 시에는 기존 기본 미리보기 텍스트를 그대로 둡니다.
- 판을 누르면 아이템·룬·스펠·지표(OP 스코어·시야·골드·받은 피해·팀 킬)가 펼쳐집니다.

## 섹션별 도시 배경
- 01 MEDIA — 강변 불빛 다리(현수교 야경·수면 반사) + 루프탑 테라스
- 02 GAMING — 랜드마크 타워 + 고가 모노레일·젖은 거리 반사
- 03 CAMPUS & SCHEDULE — 캠퍼스 시계탑(카드 위로 솟는 첨탑·시계) + 도서관 아치창·가로등 산책로
- 04 D-DAY & TASKS — 고층 스카이 라운지: 랜드마크 타워 + 유리 난간·도시 저부 야경 + 전망대 바닥
- 05 AI & TOOLS — 모던 유리 빌딩 디스트릭트: 스카이브리지·스카이 가든·층창 불빛 + 앞쪽 수면 반사
- 모든 배경은 4시간대 테마(일출·정오·일몰·심야)의 CSS 변수만 사용해 색이 바뀝니다.
- 03·04·05는 카드가 길어도 배경이 가려지지 않도록 카드 위(랜드마크)와 양옆·아래(거리/난간/수면)에 장면을 배치했습니다. 좁은 화면에서는 배경 아트를 86vh로 키워 카드 위로 스카이라인이 보입니다.

## 성능
- 배경은 정적 그라데이션 + 벡터 도형만 사용합니다(섹션 배경 SVG는 애니메이션 없음).
- 무거운 `backdrop-filter`, 대면적 `filter: blur`, 필터 키프레임 애니메이션을 제거했습니다.
- 우측 상단 **⚡ 경량** 토글: 배경 블러·미세 애니메이션·패럴랙스를 끄는 저사양 모드.
